1. Veri Nasıl Çekilir?

Discord kanalındayken CTRL + SHIFT + I tuşuna basın, "Console" sekmesine gelin ve aşağıdaki kodu yapıştırın. ROL_ID_YAZIN yerine birimin rol ID'sini girin.

(async () => { const rId = "ROL_ID_YAZIN"; const { GuildMemberStore, UserStore } = Vencord.Webpack.Common; const gId = window.location.pathname.split('/')[2]; const raw = GuildMemberStore.getMembers(gId); const m = Object.values(raw).filter(x => x.roles.includes(rId)).map(x => ({ id: x.userId, name: x.nick || UserStore.getUser(x.userId).username })); console.log(JSON.stringify(m)); alert(m.length + " kişi hazır."); })();

2. Yoklama Nasıl Alınır?

Konsoldan kopyaladığınız veriyi Yoklama sekmesindeki kutuya yapıştırın. "Listeyi Yükle" butonuna basın. Personellerin durumunu işaretledikten sonra "Raporu Hazırla" butonuna basın. Rapor otomatik kopyalanacaktır.

3. Ceza Analizi Nasıl Yapılır?

Discord ceza-log kanalındaki mesajları kopyalayın, Ceza Analizi sekmesine yapıştırın ve "Logları Analiz Et" butonuna basın. Hatalı cezaları X butonu ile silebilirsiniz.
