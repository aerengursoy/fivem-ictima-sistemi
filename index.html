GÜN SONU RAPORU

KANIT RAPORU ANALİZİ

Discord'daki el koyma raporlarını buraya yapıştırın. Sistem sadece belirttiğiniz birime ait (Örn: 72-) raporları ayıklar ve ele geçirilen eşyaları listeler.

Bulunan Eşyalar:

1. Yoklama Verisi Nasıl Çekilir?

Hangi birimin yoklamasını alacağınızı seçin, ardından aşağıdaki kodu kopyalayıp Discord'da CTRL + SHIFT + I yaparak "Console" sekmesine yapıştırın.

2. Kanıt (Mesaj) Verisi Nasıl Çekilir?

Discord'da el koyma raporlarının atıldığı odadayken aşağıdaki kodu konsola yapıştırırsanız, BUGÜN atılan tüm mesajlar kopyalanır. Ardından "Kanıt Analizi" sekmesine yapıştırabilirsiniz.

(async () => { const { MessageStore, SelectedChannelStore, GuildMemberStore, UserStore } = Vencord.Webpack.Common; const cId = SelectedChannelStore.getChannelId(); const gId = window.location.pathname.split('/')[2]; const msgObj = MessageStore.getMessages(cId); let msgs = msgObj.toArray ? msgObj.toArray() : (msgObj._array || Object.values(msgObj)); const today = new Date(); today.setHours(0,0,0,0); const todayMsgs = msgs.filter(m => m && m.timestamp && new Date(m.timestamp) >= today && m.content); const result = todayMsgs.map(m => { return m.content.replace(/<@!?(\d+)>/g, (match, id) => { let member = GuildMemberStore.getMember(gId, id); let user = UserStore.getUser(id); let name = member && member.nick ? member.nick : (user ? user.globalName || user.username : id); return "@" + name; }); }).join('\n\n'); if(result.length > 0) { copy(result); alert(todayMsgs.length + " mesaj kopyalandı! Şimdi Kanıt Analizi sekmesine yapıştırabilirsiniz."); } else alert("Bugün hiç mesaj bulunamadı veya yüklenmedi (Lütfen Discord'da biraz yukarı kaydırıp mesajları yükleyin ve kodu tekrar çalıştırın)."); })();

3. Yoklama Nasıl Alınır?

Konsoldan kopyaladığınız veriyi Yoklama sekmesindeki kutuya yapıştırın. "Listeyi Yükle" butonuna basın. Personellerin durumunu işaretledikten sonra "Raporu Hazırla" butonuna basın. Rapor otomatik kopyalanacaktır.
